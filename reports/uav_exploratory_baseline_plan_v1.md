# Moxitaidi UAV 探索性分割基线方案 v1

状态：方案草案；尚未训练，正式协议未冻结。本方案不改变现有清单和任何审批状态。目标是建立 Moxitaidi UAV-0.6m 单平台分割流程，验证数据读取、训练和验证能否运行，为后续 E1 做准备；结果不代表论文正式上界，也不作为正式跨平台结果。

## 数据边界与风险

仅读取统一清单中 `platform=UAV`、`component=2` 的 `train_candidate`（484）和 `val_candidate`（71）。只用训练候选进行参数更新，验证候选用于探索性的模型诊断。`test_candidate` 不做推理、指标计算、阈值选择或调参；`buffer` 和 `unassigned` 不参与训练或验证。候选测试区域以前已被探索，不能称为完全未接触的盲测集；正式测试如何处理留待协议决定。

现有统一清单所有正式训练和评估批准字段均为 False。本方案描述可能的探索性使用，不构成对正式使用的批准，也不更改字段；启动任何训练前应确认探索性使用的授权和适用范围。最大连通组内部已有间隔检查，仅覆盖相对网格和既定条件；跨连通组、跨平台空间关系及最终有效像素掩码未确认。名称不重复不等于地理上不重叠。禁止将此方案或局部配准称为全域无泄漏验证。

## 数据和有效像素

按清单的完整文件名匹配 `data/raw/CAS/Moxitaidi_UAV_0.6m/img/` 和 `mask/`；任一文件缺失、重复、尺寸不符、无法读取或标签出现未知值时停止并记录，不擅自跳过或改写。当前文件级检查仅确认 555 对路径存在。已有审计表对这 555 条记录的影像均记为 512×512、3 通道，mask 均为 512×512、1 通道，取值均记录为 `0 1`，issues 为空；这是历史审计，不是本次重新打开影像的结果。依据现有审计代码，1 表示滑坡，0 表示背景；读取实现上线时须对训练及验证候选重新验证取值、尺寸和对应关系，并记录异常。

已有无数据候选规则将与边界上下左右连通、所有通道均为 0 或均为 255 的像素作为候选。它已与滑坡正类标注发生重叠；README 记录 UAV 全子集重叠 274,141 像素，说明可能误删真实滑坡，不能直接当作已验证的最终有效掩码。

暂行方案：首次流程验证把所有具有合法标签值的像素视为**暂用统计范围**，训练损失和验证指标采用相同范围，明确记录这是全图假设而非已确认的真实有效区域；不可声称这些像素都真实有效。若后续核验发现明确的无效像素且能可靠定位，再定义独立版本的有效掩码，将其应用于损失和全部指标，并记录来源、覆盖率与剔除的正类数量。没有可靠依据时，不静默将黑白候选作为 ignore 区。

敏感性检查（待验证，不作为正式结论）：限定训练/验证候选，先统计候选区覆盖率、与正类交集及每图差异；在相同预测和固定阈值下比较全图统计与排除候选区的统计，同时报告被排除的总像素和正类像素。后一种仅作为有误删风险的诊断情景，不用于认定哪种口径正确，也不根据它挑选测试方案；最终处理和可比性须经技术复核及协议确认。

## 流程与记录

1. **数据检查**：复核当前文件检查报告、清单哈希、审批状态和训练/验证边界；用仅限上述候选的数据读取验证尺寸、通道与标签值。失败则先排查。
2. **数据读取**：按同名文件建立样本，影像和 mask 保持空间对应；任何几何变换必须同步应用，mask 使用最近邻插值并保持 0/1。归一化和增强方法事先固定，统计量只从训练候选估计，验证数据不参与拟合。
3. **小规模冒烟测试**：经环境和使用范围确认后，从训练候选取少量样本，验证输入形状、前向计算、损失、反向传播与参数更新，再从验证候选检查评估流程。只验证能否运行，不以其指标作为性能结论；不访问测试候选。
4. **探索性训练**：选择一个简单的二分类分割模型和明确损失（例如逐像素二元交叉熵，具体模型及配置待环境确认后固定）。仅使用训练候选更新参数；损失衡量预测与标注的偏差，供优化和诊断，不等同于 IoU。
5. **验证**：切换评估模式，在验证候选上按事先固定的概率阈值（暂定 0.5）计算损失、滑坡类 IoU、F1、Precision、Recall。所有统计排除已确认的无效像素；在尚无已验证掩码时明确标为上述全图暂用范围。验证用于探索性诊断，反复基于它选择模型会使验证结果偏乐观。

固定并记录随机种子、数据增强、模型、初始化、损失、优化器、学习率、批大小、训练轮次、阈值与停止规则；记录 Python/依赖版本、设备和驱动、代码 Git 提交及未提交差异、输入清单与脚本的 SHA-256、实际使用的文件列表版本、运行日志和结果。固定随机种子并不能保证所有硬件运算完全确定；记录非确定性设置。正式比较需要独立确认重复次数、资源和协议。无需设定必须达到的精度；探索性结果与任务书正式结果分开标记。

## 指标定义及聚合

只在声明的统计范围内计数：TP 为正确预测的滑坡像素，FP 为误报滑坡的背景像素，FN 为漏报的滑坡像素。IoU = TP/(TP+FP+FN)，衡量预测与标注的交并比；Precision = TP/(TP+FP)，衡量预测为滑坡的像素中有多少正确；Recall = TP/(TP+FN)，衡量实际滑坡中有多少被找到；F1 = 2TP/(2TP+FP+FN)，综合 Precision 与 Recall。

任一指标分母为 0 时该指标记为“未定义”（NA），不默认记作 0 或 1；同时报告对应分母、NA 数量。没有任何有效像素的图像不计入像素指标，并单独报告数量；若整个验证集无有效像素，停止评价并排查。损失也仅在声明的有效范围归一化。

暂定主要报告**整组像素汇总**：先对验证集累加 TP、FP、FN，再计算各项指标，并同时给出计数与有效像素数。可附加**逐图平均**：每图单独计算指标后，只对该指标定义了的图取算术平均，分别报告纳入图数、NA 数和总图数。这两种方式权重不同，分别标识，不可混用或视为等价；图块间可能重叠，同一地面位置可能被多次计数，不能解释为独立地面面积精度。
