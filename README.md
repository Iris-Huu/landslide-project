# 卫星到无人机的跨平台滑坡分割

Satellite-to-UAV Landslide Segmentation: Decomposing and Bridging the Cross-Platform Gap with Co-located Imagery

## 项目简介

本项目研究在卫星影像上训练的滑坡分割模型，迁移到无人机影像时可能出现的性能差距。

研究工作包括：

1. 量化卫星到无人机的跨平台分割差距。
2. 分析平台、地域和分辨率等因素的影响。
3. 在不使用目标无人机训练数据人工标注的条件下，尝试缩小差距。

当前处于第一周的数据审计与切片网格重建阶段。

### 切片网格

- UAV：984 张切片形成 8 个相对连通组；组内 3162 对按坐标应当重叠的切片，重叠区域逐像素一致。
- 卫星：652 张切片形成 164 个相对连通组；组内 1409 对按坐标应当重叠的切片，重叠区域逐像素一致。
- 网格坐标是各连通组内部的相对坐标，不是地理坐标。
- 不同连通组之间仍可能存在尚未识别的重叠。

## 已知问题

1. 当前“与边缘连通的纯黑或纯白像素”候选无数据区规则，会误选部分疑似高亮滑坡地表，不能直接作为训练或评价用的最终掩码。
2. 卫星数据中有 149 张切片尚未通过当前匹配规则找到邻居，不能因此认定它们空间独立。
3. 卫星与无人机影像是否存在可可靠配准的共同区域，尚待验证。
4. 训练、验证和测试集尚未完成最终空间划分。
