# 卫星到无人机的跨平台滑坡分割

本项目研究：在卫星影像上训练的滑坡分割模型，能否应用到无人机影像，以及平台、地域和分辨率差异会带来多大影响。

## 当前进度

项目目前处于**第一周：数据审计和实验准备**，尚未开始正式模型训练。

已经完成的主要工作：

- 下载并检查 CAS Landslide 数据集和 GDCLD 测试包。
- 对 CAS 各影像子集进行文件清点和掩码抽查。
- 完成 Moxitaidi 卫星和无人机重点子集的基础审计。
- 重建两个重点子集的相对切片网格，并检查组内重叠。
- 完成部分卫星与无人机影像的局部配准和目视检查。
- 建立无人机空间划分候选，并检查候选区域的组内缓冲距离。
- 开展局部频谱和高斯模糊匹配探索，保存结果及复现脚本。
- 检查 GDCLD 芦山影像与标签的基础元数据。

上述结果中，空间划分、配准范围和分辨率分析仍有待进一步验证。

## 数据审计结果

| 数据 | 影像数量 | 平均滑坡像素占比 |
|---|---:|---:|
| Moxitaidi SAT | 652 | 7.18% |
| Moxitaidi UAV-0.6m | 984 | 10.49% |

滑坡像素占比按整张掩码计算，尚未排除无数据区。

网格重建结果：

- UAV：984 张影像形成 8 个相对连通组；3162 对组内重叠影像的对应像素一致。
- SAT：652 张影像形成 164 个相对连通组；1409 对组内重叠影像的对应像素一致。
- 网格坐标只表示各连通组内部的相对位置，并非地理坐标；不同连通组之间仍可能存在未识别的空间重叠。

## 当前需要解决的问题

1. 完成正式训练、验证和测试空间划分，检查不同连通组及卫星与无人机之间的潜在泄漏。
2. 完善无数据区处理。目前的黑白像素候选规则存在误判，不能直接作为最终掩码。
3. 扩大同址配准和分辨率检查范围；目前尚未得到绝对有效分辨率。
4. 进一步确认 GDCLD 芦山影像来源，并检查影像与标签的对齐。
5. 核实模型权重访问状态，配置后续训练所需的 PyTorch 和 GPU 环境。

## 目录说明

- `src/data_audit/`：数据、掩码和分辨率审计。
- `src/grid_reconstruction/`：切片匹配、网格重建和验证。
- `src/registration/`：卫星与无人机影像配准及探索。
- `data/interim/`：网格、配准和候选划分结果。
- `reports/tables/`：审计统计表。
- `reports/figures/`：检查和可视化图片。

原始数据、模型权重和大部分包含遥感原图的预览图片不包含在 Git 仓库中。
